### 屏幕上的代码

```text
S_cand = saSwap(S_curr)
delta_C = cost(S_cand) - cost(S_curr)
IF delta_C <= 0 OR rand() < e^(-delta_C/T):
    S_curr = S_cand
    IF legal and better: S_best = S_curr
T = T * alpha
```
